## Полное описание для GitHub Releases / Соцсетей (Full Description)

### RU
PowerOFF — это компактное десктопное приложение для управления питанием компьютера по таймеру. Программа позволяет запланировать выключение, перезагрузку или перевод системы в режим сна с отображением визуального отсчета в реальном времени.

**Основные функциональные возможности:**
- Три режима завершения работы: выключение ПК, перезагрузка, перевод в режим сна.
- Асинхронный таймер с плавным круговым индикатором прогресса.
- Звуковой сигнал за 3 секунды до срабатывания запланированного действия.
- Переключение между темной и светлой темами оформления.
- Интеграция с реестром Windows для настройки автозапуска при старте системы.
- Автономный исполняемый файл, не требующий предварительной установки окружения Python.

### EN
PowerOFF is a compact desktop utility designed for scheduled power management on Windows. The application allows users to set a timer for shutting down, restarting, or putting the system to sleep with a real-time visual countdown.

**Key Features:**
- Three power modes: system shutdown, reboot, and sleep mode.
- Asynchronous countdown timer paired with a smooth circular progress indicator.
- Audio alert triggered 3 seconds prior to the scheduled power action.
- Toggle support for dark and light interface themes.
- Windows registry integration for autostart capability.
- Standalone executable operation requiring no pre-installed Python environment.
